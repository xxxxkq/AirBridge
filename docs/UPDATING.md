# GitHub更新与本机数据

## 用户操作

位置：偏好设置 → 软件更新。

界面采用两行卡片：标题旁展示版本与当前策略标签，右侧为检查按钮和“⋯”菜单，下面仅显示一行简短状态。自动检查开关、正常提醒、四种处理策略及更新日志统一位于菜单；“忽略本次更新”仅在发现版本时可用。目录入口统一放在数据位置卡片，迁移表单默认收起。

- 自动检查默认关闭。开启后延迟约15秒开始符合策略的首次检查，之后每12小时检查一次，成功检查时间持久化；失败退避约1小时。不自动下载或安装。
- 自动检查关闭时仍可手动点击“检查更新”；关闭自动检查不取消用户发起的手动下载。
- 本次跳过：停止本次运行的自动检查/提醒，重开软件后解除。
- 今日跳过：保存本地日期，当天不自动检查；次日恢复正常检查周期。
- 忽略本次更新：保存发布标签，不再自动提醒该版本，仍检查未来新版本。
- 禁止更新：关闭自动检查，阻止软件内检查和下载，并取消正在进行的检查/下载。在菜单中选择“正常自动提醒”或重新开启自动检查即可解除。浏览器中的“发布页”仍可手动访问。
- 手动检查可重新查看被跳过/忽略的版本，但不能绕过“禁止更新”。

点击下载后按大小、SHA256和EXE文件版本校验。单文件正式版显示“更新并重启”；开发版/多文件运行版仅提供下载目录，避免只替换EXE导致组件不匹配。

## 来源与发布要求

固定来源为 `https://api.github.com/repos/xxxxkq/AirBridge/releases/latest`。只接受高于当前版本的非草稿、非预发布版本，版本标签格式如 `v3.0.66`。日常源码可继续沿用3.0.65，但真正对外发布更新必须使用更高版本，并同步EXE版本信息。

发布附件必须包含一个名称严格为`AirBridge.exe`的正式单文件。下载URL限制在该仓库的Release资源路径；HTTPS重定向仅允许GitHub的指定下载域名；必须有GitHub API提供的`sha256:`摘要，大小限制为1KB至50MB。缺摘要、来源不符、版本无效或无权访问时不会安装。

客户端不含GitHub Token，不上传设备、日志或配置。公开可访问的Release可免登录检查；私有仓库需另设计认证，不能内置个人令牌。当前校验是HTTPS来源约束和SHA256完整性检查，不是独立发布者数字签名；GitHub账号与发布权限仍需保护。

2026-11-10仓库已按用户授权公开，匿名仓库API已验证可访问。仍需发布正式Release及附件才能提供下载更新。客户端对latest的404追加匿名仓库检查，区分未公开/无权访问与公开仓库尚无正式发布。

另定位到旧编译目标下.NET默认协议仍为SSL3/TLS1.0。更新连接现明确使用TLS1.2；优先读取HTTPS_PROXY/HTTP_PROXY（含小写）与NO_PROXY，没有环境代理时遵循系统默认代理，不修改系统设置或放宽证书验证。失败状态区分TLS、证书、代理、DNS、限额和元数据错误。实际正式版代码只读联网验证已返回repository-access，使用Tls12且没有自定义证书放行。

本次没有创建GitHub Release或进行真实在线更新。仓库没有公开正式Release时，界面提示尚无可访问发布；旧版本不会自动获得本次更新功能，首次需要手动替换一次。

## 替换和恢复

1. 用户主动点击“更新并重启”，校验下载，生成带随机ID的安装事务，启动一个临时更新进程；没有常驻更新服务。
2. 当前程序按正常退出流程释放手机并恢复输出。更新进程按PID和启动时间等待主程序、恢复守护及手机进程，最多共60秒。不主动杀音频进程。
3. 未退出或输出恢复记录仍有待处理项时取消安装。成功关闭后重新校验暂存文件，以同目录临时文件加`File.Replace`原子替换单文件，保留旧文件。
4. 启动新程序，界面完成首次呈现后写启动确认；旧文件归档到事务目录。启动立即失败时尝试还原并重启旧文件。
5. 若新程序仍运行但20秒内未确认，不强杀、不替换其正在使用的文件；保留备份及结果供手工排查。断电、权限变化等场景不能承诺全部自动恢复。

EXE目录不可写时不会自动提权。替换期间会在EXE旁短暂产生`.update-随机值`和`.previous`文件；正常成功后清理临时文件并把备份归档到用户数据目录，异常时可能保留`.previous`供恢复。

## 本机数据位置

单文件是分发形式，不是“零数据文件”。默认根目录：`%LOCALAPPDATA%\AirBridge\`。

也可在偏好设置选择“软件旁的Data”或自定义位置；下表路径相对于实际选中的根目录。单文件缓存、更新下载、安装事务和恢复守护均跟随新位置。切换流程与保留范围见`STORAGE.md`，待切换时先重启再安装更新。

| 内容 | 相对根目录 |
| --- | --- |
| 设置及备份 | `settings.json`、`settings.json.bak` |
| 电量缓存 | `phone-battery.json`、`headset-battery.json` |
| 桌面/手机/更新日志 | `AirBridge-desktop.log`、`phone-channel.log`、`update-error.log`等 |
| 未完成的输出恢复记录 | `AirBridge-default-output-recovery.xml`、`AirBridge-app-routing-recovery.xml` |
| 单文件解包缓存 | `runtime/<内容哈希>/` |
| 已下载更新 | `updates/downloads/` |
| 更新事务、结果与旧EXE备份 | `updates/jobs/<随机ID>/` |

录音组件输出到用户选择的目录，不自动混入日志。分享软件只需要正式单文件EXE，不应分享这些本机数据。不要在运行中删除runtime、updates或输出恢复记录。更新区目前保留历史事务和备份，尚未自动按数量清理；完全退出后可按需清理已完成事务，保留最近可回退项。


测试使用固定JSON、临时文件和自行启动的短时测试进程，覆盖策略、元数据校验、文件替换/回滚及PID代次等待，不访问GitHub、不启动真实界面、不终止用户进程或更改系统输出。完整在线下载安装、界面布局和真实音频退出恢复仍需手动验收。
