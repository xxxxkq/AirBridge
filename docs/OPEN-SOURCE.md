# 开源范围与贡献

AirBridge 自有源码采用 GPL-3.0-only，完整条款见根目录LICENSE。第三方文件保留原版权和许可；NAudio依赖为MIT，上游AAP研究材料的GPL许可位于对应目录。

公开内容包括C# / WPF、原生C++采集、构建/测试脚本、项目规则和设计文档。Optional仅是停止开发的历史研究，不属于默认构建，不建议安装其驱动。发布构建会排除自检、故障模拟及实验入口。

用户配置、录音、设备日志、缓存、签名私钥、构建工具下载和旧发布目录不属于源码发布。测试地址使用虚构值或由运行测试的人显式提供；不要提交个人机器路径和真实设备标识。

贡献前阅读AGENTS.md与docs/DEVELOPMENT.md，说明问题、改动和验证。涉及音频采集、连接所有权或输出恢复的改动需要相应离线回归；真实设备验证单独说明，不能仅凭构建通过承诺兼容全部机器。

单文件GPL发行包须包含LICENSE和第三方声明。对外分发二进制时，应提供对应源码的明确版本/提交位置，保留许可证并遵守源码提供要求；不要只给出无法对应二进制版本的浮动main链接。

Fork可按许可修改并分发；发行自己的软件时应修改固定GitHub更新源，避免用户被更新回本项目的发行包。自动检查默认关闭，不内置个人Token。

本次开源准备不创建新版本号，也不自动发布GitHub二进制Release。源码公开后，更新API可匿名访问仓库；检测更新仍需要另行发布更高版本的正式Release及AirBridge.exe附件。
