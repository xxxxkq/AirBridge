# 项目进度

更新日期：2026-11-11。源码维护基线：3.0.65。本文区分已实现与实机验证，历史完整变更仍保留在 `README.txt`。

## 已完成

- C# + WPF 桌面迁移，保留底层 C++；运行时不加载 PowerShell。
- 音频设备统一卡片，手机/耳机及普通音频端点模板、忽略与不可用分组、搜索、电量缓存、信号展示。
- 节点图支持输入、输出、处理中间节点；编辑/删除、自动排布、缩放、小地图及活动连线效果。
- 手机独立采集、工作进程和 IPC，按设备核对来源；支持双手机通道，暂停不应触发零帧重连。
- 既有均衡器、音量、静音、混音/切换、变声、WAV、RTP/UDP 等组件。能力受输入与隔离方式限制，不能据此承诺全部输入支持任意处理链。
- 默认 Windows 单应用路由；可选 VB-CABLE 支持电脑媒体和应用的效果链/多输出。单条 Cable 为混音端点，不能提供任意多个应用的独立隔离总线。
- 输出恢复日志与独立守护，停止/退出时恢复接管前输出；启动自动恢复上次运行意图，手动停止后不自动恢复。
- 托盘 Mini 面板、开机入口、语言、主题、热键、窗口行为与侧栏动画。
- 手机缓冲高级参数、有限丢弃与交叉淡化、根据 PCM 到达抖动调整缓冲；不再只增不减。
- 近10秒手机缺音率：排除启动蓄积，连续2秒无帧显示等待；主动丢弃量放悬浮提示。指标是渲染所需音频缺失占比，不是无线丢包率。
- 侧栏收起56px、展开176px，图标固定中轴；页面左边距收起12px、展开28px，画布分别8px/12px。

## 输出偏好与后台进程（沿用3.0.65）

同名入口包含1个主程序、每台手机1个采集进程，以及按需1个输出恢复守护；双手机通常4个。当前退出后未检测到残留，最近手机工作进程日志记录释放完成。WMI读取命令行受限，未逐一证明历史所有PID身份。支持与诊断页补充此说明，保留手机故障隔离和崩溃恢复。

设备页、托盘、热键的明确输出选择，以及手动应用电脑媒体直连物理设备，会持久更新退出恢复目标，即使选择等于软件当前输出。自动恢复图不更新偏好；临时VB-CABLE仍恢复到实际设备，外部默认输出变化保留原有不覆盖策略。输出选择集中到RouteCoordinator后台任务，退出会等待，避免UI等待连接锁。

仅接入设备、系统也没有切默认且用户未选择时，不能据此推定用户偏好。没有改成“看见任何新耳机就切换”。默认输出回归覆盖显式同目标、重载恢复、无效选择、外部覆盖、虚拟临时还原，并通过原默认角色、回滚、崩溃和断开恢复测试及124项原音频离线检查。未进行真实输出切换或界面实测。
