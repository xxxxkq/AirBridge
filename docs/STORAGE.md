# 数据保存位置

在“偏好设置 → 数据保存位置”选择：

常态只显示当前路径、“打开目录”和“更改”；路径过长截断显示，悬浮可见完整值。点击更改才展开位置、路径和迁移选项；保存后收起，只有待重启时显示撤销入口，避免常态冗余。

1. 软件旁的Data文件夹：根目录为外层EXE所在目录下的`Data`，适合便携使用。
2. 自定义目录：通过目录选择器选一个本地专用目录。
3. Windows用户数据目录：`%LOCALAPPDATA%\AirBridge`，用于兼容原有安装。

已有用户不自动搬数据，仍使用原目录；设置里显示当前实际路径。选择“迁移当前配置与日志”后，目标必须为空。点击“下次启动生效”，完全退出再打开；也可以取消待生效更改。若要使用目标目录已有配置，取消迁移勾选并确认，不进行配置合并。恢复默认偏好不会重置数据目录。

## 迁移范围与安全

- 只在下次启动、上一实例和输出恢复已结束、恢复日志没有待处理条目后复制。
- 复制根目录的配置、电量JSON及备份、XML恢复记录、日志/TXT/CSV文件，逐文件校验；目标有新文件、不可写或失败时继续使用原目录，不覆盖现有配置。
- 不删除原目录。已加载runtime缓存和历史updates子目录不复制；之后的运行缓存、更新下载、事务和日志使用新根目录，旧内容保留供回退/清理。
- WAV录音不搬动，继续使用录音节点指定目录。
- 新旧数据目录不能互相包含，不支持磁盘根目录、UNC网络目录或作为数据根目录的链接。
- 数据位置待生效时禁止安装更新，需先重新启动让位置稳定，避免安装事务根目录变化。

## 位置描述文件

配置选项保存到外层EXE旁的`AirBridge.storage.xml`及小型`.bak`备份（若EXE更名，则跟随该名字）。因此EXE目录需要可写；不自动提权。默认未配置时不创建该文件。

portable模式以`Data`相对EXE的位置解析，不固定个人绝对路径。移动自己的便携版时，应一起移动EXE、位置描述文件和Data目录；只复制EXE到其他位置不会携带配置。自定义模式保存所选绝对路径，移动软件时要带上描述文件，并保持数据目录可访问。

单文件指程序分发为一个EXE，不意味着没有配置和日志。对外分享只发正式EXE，不带个人Data目录或自定义位置文件。

## 实现与验证

`Shared/DataLocation.cs`同时编译进单文件启动器和运行组件。启动器先解析位置再解包；主程序、手机子进程、恢复守护和临时更新进程保持同一运行期根目录，避免配置待生效时混用两个位置。第二次启动优先通知已有实例，不在运行期间执行迁移。

```powershell
.\Scripts\Test-DataLocation.ps1
```

23项隔离文件测试覆盖下次启动切换、恢复占用阻断、非空日志阻断、复制校验、旧目录保留、便携移动、自定义路径、已有配置不合并、取消、重叠目录、录音不迁移及位置文件备份。不访问用户真实AppData或切换音频；实际设置界面和真实迁移尚需用户手动验收。
